# Análise da Tabela 3 — Áreas gerais de formação na graduação (IBGE, Censo)

Notebook `analise_tabela3.ipynb` (pandas + numpy) que divide a Tabela 3 em três tabelas de homens e mulheres por Grande Região:

| Arquivo | Conteúdo |
|---|---|
| `tabelas/superior.xlsx` | Pessoas com curso superior (todas as áreas) |
| `tabelas/tecnologia.xlsx` | Ciência, Tecnologia, Engenharias e Matemática |
| `tabelas/educacao.xlsx` | Educação, Serviços pessoais, Saúde e Bem-estar |

Cada tabela é analisada com `describe()`.
